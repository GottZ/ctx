# ctx_discord_policy

Per-server Discord policy for [Hermes](https://github.com/NousResearch/hermes-agent): the bot can take part in
server conversations while tools stay reserved for the operator configured on the host, and each server is
configured from inside Discord.

**Status: under construction.** This branch is the scaffold of version 3.0.0; it registers nothing yet.
Installation, configuration and the security model will be documented here once the plugin is functional.
