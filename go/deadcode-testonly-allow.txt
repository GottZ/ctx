# deadcode-testonly-Allowlist — die Policy hinter `../deadcode.sh testonly` (Welle T02-13).
#
# Klasse T: Produktions-Symbole, die NUR leben, weil ein Test sie ruft. Der Lauf
# OHNE `-test` findet sie; die erste Liste (deadcode-allow.txt) wird davon
# subtrahiert, damit kein Symbol in zwei Dateien geführt wird.
#
# Format wie in deadcode-allow.txt — eine Zeile je Symbol, TAB-getrennt,
# LC_ALL=C sortiert, Vergleichsschlüssel sind Feld 1 und 2:
#
#   <pfad-relativ-zu-go><TAB><symbol><TAB># <grund>
#
# Das Gate blockiert in BEIDE Richtungen: ein neues test-only-Symbol ohne Zeile
# ist rot, und eine Zeile, deren Symbol wieder einen Produktions-Aufrufer hat,
# ebenfalls — dann gehört die Zeile gelöscht, sonst wächst die Liste zum Deckel.
#
# Die Ratsche fasst nur Funktionen und Methoden. Package-level Vars, Konstanten
# und Typen, die ausschließlich ein Test nutzt, sieht weder deadcode (meldet nur
# Funktionen) noch der unused-Linter (zählt Test-Nutzung als Nutzung und schweigt
# über exportierte Namen) — gemessen in T02-13, nicht angenommen. Für diese Klasse
# gibt es kein Gate; sie fällt beim Lesen auf oder gar nicht.
#
# Wiederkehrende Gründe (Einzelfälle tragen ihren eigenen):
#
#                             Produktions-Importeur ist der eigene Adapter, der selbst
#                             unerreichbar ist. Der Schnitt gehört der hermes-Lane.
#   wartet: E01-2 C (C2-12)   das Gen-1-Gate (W01-1) in derived und seine DB-Hälfte in
#                             store/resolve_sources.go. Achtung: das Paket derived IST
#                             verdrahtet (10 Produktions-Importeure) — es wartet nur diese
#                             Hälfte, die Prod bisher ausschließlich in Kommentaren nennt.
#   K24 dauerhaft             Registry-Fassaden, die es per Entscheid bleiben sollen.
#   E02-3 A                   Test-Fassade, bewusst behalten (Entscheid E02-3).
#   testdb                    dauerhafte Test-Infrastruktur, kein Wartezustand: das Paket
#                             trägt //go:build integration und hat 0 Produktions-Importeure.
#
# Eine spätere Welle, die eines dieser Symbole schneidet, nimmt seine Zeile hier
# im selben Commit mit.
